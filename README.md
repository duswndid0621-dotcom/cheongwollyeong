# 청월령 (青月嶺) 3.0 — Godot 프로젝트

조선시대 미스터리 공포 어드벤처. 시작 화면 → 오프닝 → 1장 「푸른 불」 → 2장 「어린시절의 꿈」 → 3장 「문을 닫는 자」 → 4장 「길이 가리키는 곳」 → 종장 「이름」 → 엔딩 크레딧까지 전부 들어 있다.
3.0부터는 이 폴더(고도트 프로젝트)가 원본이다. 고칠 것은 모두 여기서 고친다.

## 여는 방법
- **고도트로_열기(배경수정).bat** 더블클릭 → 고도트 에디터가 이 프로젝트를 연다. (바탕 화면의 Godot_v4.7.2-stable_win64.exe 를 찾아 쓴다)
- 또는 고도트를 직접 실행 → 프로젝트 관리자에서 **가져오기** → 이 폴더의 `project.godot` 선택.
- 처음 열 때 그림·소리를 불러오느라 1~3분 걸린다. (`.godot` 폴더가 새로 생기는데, 지워도 다시 만들어지는 임시 폴더다)
- 에디터 오른쪽 위 ▶ 또는 **F5** = 처음부터 실행, **F6** = 지금 열린 지역만 실행.
- **게임_바로실행.bat** = 에디터 없이 게임만 실행.

## 어디를 고치면 되나
| 고칠 것 | 위치 |
|---|---|
| 배경 그림 배치 · 크기 · 색 | `scenes/areas/<지역>.tscn` (자세한 방법: `배경_수정_안내.txt`) |
| 대사 · 선택지 | `data/dialogue.json` (1장), `data/dialogue_ch2.json` ~ `dialogue_end.json` |
| 사람 · 살펴볼 것 · 이벤트 위치, 검은 실루엣 위치 | `scripts/area_data.gd` |
| 오른쪽 위 목표 글 | `scripts/objectives.gd` |
| 아이템 이름 · 설명 | `data/items.json` |
| 엔딩 크레딧 | `data/credits.txt` |
| 이동 속도 · 연출 · 괴물 동작 | `scripts/field.gd` (맨 위 상수: 걷기 · 달리기 · 허수아비 속도) |
| 대화창 · 메뉴 · 대화 기록 · 조작 방법 창 | `scripts/ui.gd` |
| 애니메이션 | `assets/anim/<이름>/000.webp …` + `assets/anim/anim_meta.json` |

### 대사 쓰는 법 (data/*.json)
- `{"s": "최옥순", "t": "대사"}` 초상화가 있는 대사
- `{"n": "지문"}` 초상화 없는 해설
- `{"choice": [{"t": "선택지 글", "go": "이동할 label"}]}` 선택지
- `{"label": "이름"}` / `{"go": "이름"}` 흐름 이동, `{"set": "플래그"}` 기억, `{"item": "potato"}` 아이템 얻기
- `{"event": "이름"}` 연출 실행 (scripts/field.gd 의 handle_event)

## 실행 파일(.exe) 만들기
에디터 메뉴 **프로젝트 → 내보내기 → Windows Desktop → 프로젝트 내보내기**.
기본 저장 위치는 이 폴더 바로 옆의 `청월령 3.0 내보내기` 폴더다. 처음 한 번은 "내보내기 템플릿 관리"에서 템플릿(4.7.2)을 내려받으라는 안내가 나온다.

## 지금까지 (2.2 ~ 2.6 요약)
- 배경: 집 · 우물 · 서당 · 주막 · 마구간 · 신당 · 노인 초가 · 건넛방 크기 조정, 건물 · 나무가 떠 보이지 않게 밑동 맞춤, 담 겹침 정리, 맵 끝 배경이 끊기지 않게, 그라운드 라인 조정.
- 연출: 상호작용 지점 표시(별 · 말풍선), 오른쪽 위 목표, 검은 실루엣 괴물(가만히 · 바로 사라짐 · 잠깐 나타남), 허수아비 추격(달리기 1.8배, 빨라졌다 느려지기 반복), 어둑시니 둘레 도트 연기 · 도깨비불, 봉인석 뒤 거대한 그림자.
- 이야기: 주막 도착 애니메이션, 방울 뒤 걸어서 기괴한 숲으로, 돌아온 뒤 주모 대사, 다음 날 건넛방, 히든 엔딩 제거.
- 화면: 책 모양 대화 기록(L), 시작할 때 조작 방법, 게임오버 다시하기 수정, 애니메이션 건너뛰기 없음.
